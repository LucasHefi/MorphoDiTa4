# Schválená ikona MorphoDiTa — 18. 11. 2026

Uživatelem schválený návrh: písmeno M / otevřená kniha s tyrkysovým větvením na tmavě modrém zaobleném čtverci. Vygenerováno vestavěným imagegen, původní návrh beze změny uložen jako `approved-icon.png`.

Nasazení 0.1.21 používá standardní `tauri icon` pro změnu velikostí a formátů; nešlo o nové grafické generování ani úpravu motivu. Desktopové varianty jsou v `morphodita4/src-tauri/icons/`, favicon a webová ikona v `morphodita4/public/`. NSIS má výslovně nastavenou novou ikonu instalátoru i odinstalátoru.

Kontroly balíčků a instalace: `docs/verification/2026-11-18-release-0.1.21/`.
