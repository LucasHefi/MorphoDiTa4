# Canonical lemma regression fixtures

155 ordinary Czech word forms of akcionář / akcionářský, covering diacritics, negation and inflection. Captured tagger and companion-dictionary responses used by wizardLemmas.test.ts. These files contain only linguistic test inputs/expected values and API responses; local QA reports, database identifiers, process information and paths are excluded.

Source responses: local MorphoDiTa with Czech MorfFlex 2.1 / PDT-C 2.0 (250909), including its no_dia companion. Original acknowledgement URLs are retained in the response objects. No model weights are included; model provenance and terms: https://hdl.handle.net/11234/1-5985 .
